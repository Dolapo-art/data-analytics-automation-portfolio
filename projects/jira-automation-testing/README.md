# Testing Jira Automation Rules in a Live Kanban Workflow

## Purpose
Verify that Jira automation rules behave as intended across issue creation and workflow transitions.

## My contribution
Designed and tested custom automation rules on a Kanban board, including welcome comments generated when issues were created. Used test issues to examine behaviour across To Do, In Progress, In Review and Done.

Checked trigger execution and reviewed the issue activity feed for automation-generated comments and resolution timestamps. The work applied a quality-assurance approach to rule behaviour and edge cases.

## Tools
Jira · Jira Automation · Kanban · test issues · activity-log review

## Deliverable
Tested rule behaviour and issue lifecycle checks. Collaborative project associated with Alluvium.
