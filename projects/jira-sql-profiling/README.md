# Connecting to a Jira Database in DBeaver and Writing SQL Queries

## Purpose
Summarize the data footprint of a Jira PostgreSQL instance in a readable query result.

## My contribution
Connected to the database in DBeaver and wrote a SQL statement using multiple `SELECT COUNT(*)` subqueries. Meaningful aliases organized counts for categories such as projects, issue types, workflows, custom fields, priorities and statuses into one result row.

Focused on clear formatting and readable query structure. The database exploration provided a foundation for repeatable extraction and Python-based reporting.

## Tools
SQL · PostgreSQL · DBeaver

## Deliverable
A consolidated resource-count query for database profiling and instance analysis.
